# yyscbghelper

阴阳师藏宝阁（yys.cbg.163.com）账号分析浏览器扩展 —— 打开商品详情页，自动读取页面已加载的账号数据，在页面内展示一速、配装、胚子、输出面板与资源情况。

> Chrome / Edge · Manifest V3 · 无构建步骤 · 无依赖 · 纯本地运行

---

## 功能

**一速分析**
- 散件一速、套装一速，多套独立拆分（按御魂 UUID 去重，互不冲突）
- 逐位置显示副属性速度与主属性
- 头 / 尾 / 脖子按「位置 + 主属性 + 满速」判定

**配装工作台**
- 自选四件套 / 两件套 / 2·4·6 号位主属性（速生生、速生暴、速命生、速抵生、速攻暴等）
- 支持满暴约束、速度下限
- 实时给出 1~6 号位的具体御魂与属性贡献

**输出面板**
- 雪御前 / 平将门为主，覆盖天照、须佐之男、阿修罗、神堕八岐大蛇、烬天玉藻前
- 面板口径：**总攻击 × 暴伤**（与游戏内御魂计算器一致）
- 平将门区分攻击架势 / 防守架势两种形态

**御魂胚子**
- 四腿满条、二号位双速、速度跳数（6/5/4 跳）
- 8~9 条极品输出 / 辅助胚子、10 分+ 首领御魂

**资源全景**
- 勾玉、蓝票、魂玉、黑蛋、逆鳞、逢魔之魂、勋章、荣誉等
- 皮肤 / 典藏 / 庭院 / 召唤屋 / 幕间收集情况

**多账号对比**
- 对比篮，可导入本地已下载的原始 JSON 同屏比较
- 导出 CSV 对比报告

## 安装

1. 下载本仓库（`Code` → `Download ZIP`）或 Releases 里的压缩包，解压到任意目录
2. 打开 `edge://extensions`（Edge）或 `chrome://extensions`（Chrome）
3. 打开右上角「**开发者模式**」
4. 点「**加载解压缩的扩展**」，选择含 `manifest.json` 的那个文件夹
5. 打开任意藏宝阁商品详情页，右侧会自动出现工作台

> 需要 Chromium 111 及以上（使用了 `content_scripts.world: "MAIN"`）

## 口径说明

| 项目 | 口径 |
|---|---|
| **面板** | 总攻击 × 暴伤。只此一项，不折算任何套装增伤系数 |
| **满暴** | 硬约束。求解时「满暴 > 暴击更高 > 面板更高」，不会为了面板牺牲暴击 |
| **一速** | `57 + 六个位置各自最高的副属性速度`；2 号位只在「主属性为速度」的御魂里取 |
| **套装一速** | 四件套占 4 个位置 + 另 2 位用最快散件，穷举 `C(6,4)=15` 种分配取最优 |
| **头 / 断头 / 脖子** | 头 = 2 位速度主属性 + 副属性 16/17；断头 = 只到 15；脖子 = 歪一手 12~14 |
| **胚子** | 六星未满级 + 副属性含速度；满级 15~18 速属于「满速」，不计入胚子 |
| **主属性** | 1/3/5 号位固定为攻击 / 防御 / 生命；2/4/6 号位按御魂数据推断，推断失败按位置给输出向默认值并标注 |
| **两件套** | 攻击+15% / 暴击+15% / 生命+15% / 防御+30% / 命中+15% / 抵抗+15%；首领御魂为唯一被动，不带属性 |

## 已知限制

- 套装名需与游戏内中文名完全一致，未知套装不加成
- 配装求解为「每位置取该套装该主属性最优」，非全局最优（全局最优需要 beam search）
- 大御魂量账号（5000+）首次解析约数百毫秒，期间面板可能稍晚出现
- 仅适配中文版藏宝阁页面结构

## 开发

无需构建，改完源码直接在扩展页点「重新加载」。

```
manifest.json          MV3 配置
config/                配色、头像框等配置常量
content/
  content-bridge.js    ISOLATED world，消息桥接
  content.js           主逻辑（页面注入、解析、渲染）
popup/                 工具栏弹窗
icons/                 图标资源
updates/               更新日志
```

调试：在藏宝阁页面按 `F12` 打开控制台，日志前缀为 `[yyscbghelper]`。
